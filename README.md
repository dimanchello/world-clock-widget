# Obsidian World Clock Widget — плагин для Obsidian

Виджет мировых часов для Obsidian: отображает время коллег в разных часовых поясах, рабочие часы и статус занятости.

## Возможности

- **Мировые часы** — отображение текущего времени в выбранных часовых поясах с автоматическим обновлением каждую секунду
- **Рабочие часы** — настройка рабочего времени для каждого контакта с визуальным статусом «на работе» / «не работает»
- **Уведомления** — системные уведомления (HTML5 Notification API) о начале и окончании рабочего дня коллег с дедубликацией (одно уведомление в день на событие)
- **Перетаскивание** — изменение порядка карточек drag & drop прямо в виджете
- **Редактирование** — создание и редактирование часовых карточек через модальное окно с иерархическим выбором часового пояса
- **Мультиязычность** — автоматическое определение языка интерфейса (русский / английский)
- **Тёмная и светлая тема** — использует CSS-переменные Obsidian

## Установка

### Ручная установка

1. Скачайте файлы `main.js`, `manifest.json` и `styles.css` из папки `dist/` (после сборки)
2. Поместите их в папку `.obsidian/plugins/world-clock-widget/` вашего хранилища Obsidian
3. Включите плагин в настройках Obsidian → Community plugins

### Установка из исходников

```bash
git clone <repository-url>
cd world-clock-widget
npm install
npm run build
```

Скопируйте содержимое папки `dist/` вместе с `manifest.json` и `styles.css` в папку плагина Obsidian.

## Использование

1. Нажмите на иконку часов в боковой панели или выполните команду «Открыть виджет мировых часов»
2. Откройте настройки плагина и нажмите «+ Добавить»
3. Укажите название, часовой пояс и при необходимости — рабочее время
4. Включите уведомления о начале/окончании рабочего дня (доступны только при указанном рабочем времени)
5. Измените порядок карточек перетаскиванием прямо в виджете

```bash
npm run test         # Запуск unit-тестов (vitest)

```

## Линтер и статанализ

Проект использует **ESLint** с пакетом `@typescript-eslint` и строжайшими наборами правил:
- `strict-type-checked` — максимально строгая проверка типов
- `stylistic-type-checked` — стилистические правила на основе типов

Дополнительно: явные возвращаемые типы, `import type`, обязательные `{}` для `if`, `prefer-readonly`, запрет `console`/`alert`, проверка полноты `switch`, безопасная обработка Promise.

## Поддерживаемые языки

- English (по умолчанию)
